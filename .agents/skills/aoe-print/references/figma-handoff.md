# Editable delivery to Figma

Figma is the preferred editing destination; this skill supplies design decisions, not an integration. Inspect the available tool descriptions and their actual supported operations. A Figma-reading tool or a screenshot tool does not establish write access. Do not install plugins or claim file creation without the necessary capability and authorization.

## Choose a supported delivery path

- **Verified native creation:** use a connected tool that can create the needed Figma elements. Keep text, shapes, image assets, and meaningful groups separate. Use constraints or auto layout when they support the composition; do not force a rigid component system onto expressive poster work.
- **Importable intermediate:** if native creation is unavailable, disclose this before execution. Offer an SVG layout and separate assets when the environment can produce them. SVG import fidelity, font substitution, and text editability must be tested in the destination. Paths that resemble letters are not editable text. Never label an untested import as a native Figma file.
- **Specification only:** if neither path is supported, deliver precise layout/type specifications and an asset list as a handoff, clearly labeled as such. Do not present it as the finished editable design.

Do not substitute a flattened AI image for the promised editable layout. Raster photography or illustration may remain placed image assets; exact copy and layout stay separately editable. Explain which elements remain raster.

## Build and verify

1. Confirm the selected concept, supplied copy, frame proportions, fonts available to the designer, and asset rights. Record intended physical dimensions separately from screen dimensions; a Figma frame alone does not establish print output size.
2. Name layers by role (title, date, hero illustration), keep meaningful groupings, and avoid unnecessary nesting. Preserve the ability to change a date or headline without rebuilding the poster.
3. Inspect the rendered result at thumbnail and intended reading scale. Check copy, clipping, overlap, hierarchy, and supporting-text legibility.
4. When Figma access is available, verify a representative text element can be edited and a visual element moved independently. Check the composition after import, not just the exported preview. When access is unavailable, state that destination verification remains outstanding.
5. Deliver the actual file/link, brief design rationale, and precise limitations. Use production.md for print handoff; do not infer press readiness from a successful Figma import.

For critique, prioritize at most three consequential changes. Explain each with a visible observation, its effect on communication, and a concrete adjustment. Preserve intentional tension and unusual composition when they serve the brief.
