# Object-led — selectable direction

Use when the user names `object-led` or when a familiar object can embody the message. This reference is optional, not a default for every print brief.

## Evidence
User-supplied screenshot, inspected 2026-10-05: pale portrait composition with a very large metallic paperclip, a heavy rotated headline on the left, and small separated copy blocks on the right. Creator and original URL were not supplied or verified. Do not publish the reference image or attribute it to AOE. The screenshot's apparent texture does not establish its physical paper or printing method.

## Interpretation
The object makes the language concrete: an attachment metaphor becomes the composition's subject. Scale gives an ordinary object unusual importance. Large type and small copy establish different reading speeds. The narrow vertical object organizes neighboring text.

## Apply
1. Identify the brief's central action or idea; choose an object with a clear relationship to it rather than a decorative prop.
2. Give the object enough scale and detail to carry the design. Select crop, angle, placement, and lighting according to its silhouette.
3. Build the typographic arrangement around the new object and the actual copy. Do not reproduce the source's left-rotated-headline/center-object/right-copy layout by default.
4. Preserve a pronounced scale separation: dominant object, strong but controlled title, compact supporting details. For the writing-workshop pilot, day/time/venue are tertiary information, not a subtitle or second headline. Keep them in a small, quiet group with generous surrounding space; do not expand them to occupy the open area. Estimate the source's title-to-detail relationship and specify a target relationship for the new design, then verify it visually rather than relying on the word “small.” Introduce material texture only if it supports the concept.
5. Test whether the object communicates without explanation, whether the title competes with its silhouette, and whether the small copy survives at the intended reading size.

## Limits
One observed design is an example, not proof of general effectiveness. Rotated headlines increase reading effort. A literal object can feel obvious unless scale, composition, or meaning adds something. Unknown source rights mean this study contains only original analysis; no source artwork is distributed.

## Failure learned from the first pilot
The pencil poster retained the object metaphor but inflated “Saturday / 2–5 pm / Studio 12” into a large competing block. The user rejected that hierarchy. Copy accuracy and an enlarged object were insufficient success criteria. On the next attempt, reduce the supporting block's apparent scale and occupied area, check the title against the object, and inspect both thumbnail hierarchy and full-size legibility before acceptance. No revised output has yet demonstrated that this correction is effective.
