# Object-led pilot — 2026-10-05

Method: assistant read the local AOE Print core and object-led study, then synthesized the generation prompt below. Built-in image generation received the user-supplied paperclip screenshot as a visual reference. This is a guided concept experiment, not an independent installation test or a controlled comparison.

Brief used: writing workshop; pencil as central object; Saturday, 2–5 pm, Studio 12; portrait A3 proportions. Event details are fictional demonstration copy from the conversation's proposed example.

## Exact generation prompt

Create one original flat poster design, portrait A3 proportions, visual concept proof for a writing workshop. Exact copy only: 'Writing workshop' / 'Saturday' / '2–5 pm' / 'Studio 12'. Use the supplied paperclip poster solely as a conceptual reference: a familiar object enlarged enough to carry the message, clear contrast between headline and small information, and intentional negative space. Replace the paperclip with a beautifully detailed sharpened graphite pencil, warm natural wood and charcoal-painted facets, strong tactile presence. Develop a DIFFERENT composition: confident horizontal headline at the top, pencil crossing the lower page diagonally as if poised to begin a line, small neatly aligned event details grouped in an open area. Off-white paper field, charcoal typography, subtle material detail, restrained editorial character. Make the object feel consequential rather than decorative. Keep all text fully legible and correctly spelled, deliberate spacing, no source wording or copied layout, no logo, no extra copy, no borders or room mockup. This is a flat artwork, not a photograph of a poster on a wall.

## Observed result

The generated proof retains all four copy elements, gives the pencil a dominant diagonal position, uses a horizontal two-line headline and a separate event-information block, and differs from the reference's vertical three-column arrangement. The graphite point and line make the writing action explicit. Text is legible in the preview; the headline is very heavy and tightly spaced, which should be reviewed for the intended audience.

The result is a raster concept, not an editable typeset master or verified press-ready A3 file. No baseline or text-only-reference comparison was generated, so this result cannot establish improvement caused by the skill. The assistant selected additional composition details; it does not demonstrate autonomous reference routing by another agent. GitHub publication remains pending.

## User review — failed hierarchy
The user rejected this result: the supporting event details were much too large. The earlier assessment of legibility did not test whether they were subordinate. Treat this pilot as a failure, not an accepted example.

Regression brief: repeat the same copy and object-led direction. Before rendering, specify the intended attention order and a relative type scale. Pass only if the object leads, the title remains clearly differentiated from the event details, and the date/time/location form a compact subordinate group while remaining readable at the intended size. Do not pass based on prompt wording alone; inspect the resulting artwork. This revision has not yet been visually retested.

## Second visual attempt
A new built-in image-generation proof used explicit relative hierarchy instructions: dominant pencil, secondary title, and compact tertiary event details. Visual inspection showed a substantially smaller event-information block. This was a single guided attempt without a baseline; user acceptance and independent agent testing remain unconfirmed. The later attempt does not establish reliable skill performance.
